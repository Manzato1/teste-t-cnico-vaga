 API Rick and Morty - Teste Técnico

Esta é uma API RESTful desenvolvida em Node.js com Express, como parte do teste técnico para a vaga.

 Tecnologias

- Node.js (última versão estável)
- Express.js
- JWT para autenticação
- Bcrypt para criptografia de senhas
- Axios para consumo da API externa

Instalação

Clone o repositório
   bash
   git clone ht://github.com/Manzato1/teste-t-cnico-vaga
   cd teste-t-tcnico-vaga

   Instalação de dependências:
bash
npm install
